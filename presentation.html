Problem Statement & Motivation 02 / 10

The Multimodal Grounding Gap

Why traditional text-based RAG evaluation fails in vision-language tasks

Traditional Text RAG
Token Faithfulness
  • Evaluates N-gram overlap and textual entailment against raw paragraphs.
  • Assumes retrieved text directly contains the exact target string.
  • Tools: Ragas, SelfCheckGPT, TruLens.
  • Blind spot: Blind to spatial charts, axes, coordinate ticks, and graphic legends.
Multimodal RAG (Our Focus)
Cross-Modal Visual Grounding
  • Evidence consists of bar charts, scatter plots, chemical diagrams, and dense paper tables.
  • Requires multi-step reasoning: OCR $\rightarrow$ visual perception $\rightarrow$ arithmetic deduction.
  • The Danger: A model creates convincing fabricated data while pointing to an image it misunderstood.
🔍
Key Research Question: How do we isolate visual perception and arithmetic failures from true parametric hallucinations?

The 5-Part Error Taxonomy

Why a wrong answer isn't always a hallucination

Category A · Grounded-Process Errors (Procedural)
01
Retrieval Error
The necessary evidence snippet was never fetched by dense/sparse vector search. The model failed due to an empty context window.
02
Reasoning Error
Correct evidence retrieved, but math/deduction failed (e.g. extracted $4.2M & $5.6M, but computed growth as 12% instead of 33.3%).
03
Generation Error
Model generated a sound intermediate proof for Option B, but emitted "Therefore, Option A" in the final sentence token.
04
Grounding Error (Visual Specific)
Misread chart attributes: inverted Y-axes, low-contrast dashed lines, or row/column misalignment during visual feature encoding.
Category B · Categorically Distinct Failure
05 Hallucination Error

The answer contains factual assertions unsupported by, or directly contradicting, the retrieved evidence given to the model.

SPIQA Benchmark Example:

Model asserts: "The alloy was synthesized at 450°C under argon gas as cited by Smith et al. (2021)" — when neither argon nor Smith appears anywhere in the paper.

Detection Pipeline · Stage 05 Deep Dive 06 / 10

Automated Hallucination Detection Engine

Claim decomposition, 4-tier grounding audit, and relaxed numeric tolerance

Atomic Claim Decomposition
RAGTruth Claim Auditing

The model deconstructs generated prose into independent verifiable assertions.

  • Each claim is evaluated strictly against extracted evidence pixels or text.
  • Prevents confirmation bias by cross-checking against raw OCR tables.
  • Computes the Hallucination Rate:
    Rate = (Unsupported Claims) / (Total Claims)
Numeric Verification Engine
ChartQA Relaxed Accuracy

Extracts numeric tokens (percentages, currencies, integers) and verifies them against ground truth table values:

relativeError = |given - target| / |target| ≤ 0.05

Filters out standard years (1900–2099) and ordinals (Q1-Q4) to avoid false positives.

Supported 🟢
Directly grounded by evidence data points and observable visual features.
Subtle Conflict 🟡
Minor discrepancy in rounding, units, or slight contextual misalignment.
Evident Conflict 🔴
Directly contradicts values explicitly displayed in the retrieved chart or table.
Baseless Extrapolation 🟣
Claims facts, entities, or trends nowhere mentioned in the source evidence.

Key Insight 1: Arithmetic vs Vision

Over 40% of initial 'hallucinations' in ChartQA were actually Reasoning Errors (bad arithmetic on correctly extracted numbers), validating our 5-error taxonomy.

Key Insight 2: Evidence Boundary Prompting

Constraining the model to cite specific visible visual elements eliminated ungrounded historical and entity hallucinations without harming explanation readability.
