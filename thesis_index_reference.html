Section 01 · Research Abstract

Executive Overview & Problem Statement

Large language models used for question answering can generate answers that are unsupported by, or contradict, the evidence available to them — a problem known as hallucination. Retrieval-Augmented Generation (RAG) reduces this by grounding generation in retrieved evidence, and multimodal RAG extends this further by retrieving text, images, charts, and tables together.

However, retrieving the correct evidence does not guarantee a model interprets it correctly — especially when that evidence is visual. This project reviews the literature on RAG, multimodal RAG, and hallucination detection (POPE, Ragas, RAGTruth, SelfCheckGPT), finds that no existing method has been validated on multimodal RAG systems combining more than one evidence type, and proposes an eight-stage pipeline plus an explicit error taxonomy to study the problem directly.

The Multimodal Grounding Gap
While text-based RAG evaluation framework tools like Ragas or SelfCheckGPT estimate token faithfulness, they fail when an error stems from misinterpreting a plot axis, misreading tabular column headers, or confusing figure labels. Our work fills this gap by validating explicit visual and multi-evidence hallucination metrics.
Key Question: How do we isolate visual reading failures from parametric hallucination?

Section 02 · Conceptual Core

Why a Wrong Answer Isn't Always a Hallucination

Evaluating RAG systems requires distinguishing where in the reasoning chain a failure occurred. Conflating retrieval or reasoning failures with true hallucination leads to incorrect mitigation strategies. We define a 5-part explicit error taxonomy: Items 1–4 represent grounded-process errors, while Item 5 represents a categorically distinct hallucination.

Taxonomy Categories:
Grounded-Process Errors (Types 1–4)
Hallucination Error (Type 5 · Categorically Distinct)
01

Retrieval Error

Grounded-Process Error

The evidence needed to answer the question was never retrieved in the first place (e.g. dense/sparse vector search missed the relevant figure caption or table snippet).

ScienceQA Example: Question asks about friction on a ramp. The retriever returns context on gravity and momentum, omitting the friction coefficient lecture section entirely. The model fails because necessary context was absent.
02

Reasoning Error

Grounded-Process Error

The correct evidence was retrieved, but the model reasoned about it incorrectly (e.g. valid data points were extracted, but mathematical or logical deduction failed).

ChartQA Example: The model retrieves the exact bar chart values for 2018 ($4.2M) and 2019 ($5.6M), but calculates the percentage growth as 12% instead of 33.3%. The data retrieved was correct, but calculation logic broke down.
03

Generation Error

Grounded-Process Error

The model produced an answer that doesn't match its own internal reasoning or generated rationale step (e.g. correct intermediate steps leading to a contradictory final option selection).

ScienceQA Multiple-Choice: Rationale correctly proves Option (B) is true ("Photosynthesis requires sunlight"), but the final output line outputs: "Therefore, the correct choice is (A)."
04

Grounding Error

Grounded-Process Error (Visual-Specific)

Specific to visual evidence: the model misread or misunderstood a chart, image, or table (e.g. misinterpreting line legend colors, inverted Y-axis scales, or row-column alignments).

SPIQA Scientific Diagram: The model reads a scatterplot image, but misidentifies the dashed trend line as a confidence interval or confuses blue vs red data series due to low contrast OCR/vision encoding.
05

Hallucination

Categorically Distinct Failure

The answer contains information unsupported by, or directly contradicting, the retrieved evidence given to the model — fabricating un-grounded claims, unmentioned historical facts, or imaginary data points.

SPIQA Paper QA: When asked about experimental yield from Table 2, the model asserts: "The compound was synthesized at 450°C under argon gas as noted by Smith et al. (2021)" — even though Smith et al. and argon gas are nowhere in the retrieved paper context.
Section 03 · Benchmark Evaluation Datasets

Studied Multimodal Datasets

ScienceQA

~21K Questions
Multiple-Choice · Multimodal Science

Science, social science, and language science questions with paired lecture and explanation annotations — good for testing whether a generated rationale stays faithful even when the final answer choice is correct.

Lecture Annotations Rationale Faithfulness Multiple Choice

ChartQA

32.7K Questions
Open-Vocabulary · Visual & Arithmetic

Human-written and generated questions over real-world charts requiring visual perception and arithmetic reasoning — nested operations and visual-attribute questions represent the hardest benchmark failure points.

Real-world Charts Arithmetic Reasoning Visual Attributes

SPIQA

270K Questions
Generative QA · Full Scientific Papers

Complex generative questions over figures, tables, and diagrams embedded in full scientific papers, evaluated across in-distribution and out-of-distribution research test splits.

Full Research Papers Tables & Diagrams OOD Test Splits
